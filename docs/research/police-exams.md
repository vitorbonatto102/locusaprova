# Pesquisa — concursos policiais

## Hipótese de produto

Concursos policiais compartilham uma base relevante — Português, Constitucional, Administrativo, Penal, Processo Penal e legislação especial — mas cada edital seleciona, expande e pondera essa base de modo diferente. Portanto, “PF”, “PRF” e “Polícia Civil” não devem ser cursos isolados: são configurações sobre uma árvore comum.

## Fontes estruturais verificadas

- PF 2025: [Edital nº 1 — PF — Policial](https://www.gov.br/pf/pt-br/acesso-a-informacao/servidores/concursos/edital/carreira-policial-2025/editais/edital-no-1_2025-dgp-pf.pdf/@@download/file), banca Cebraspe.
- PC-RS 2025: [Edital nº 06/2025 — Agentes](https://www.pc.rs.gov.br/upload/arquivos/202510/24083812-edital-de-abertura-agentes-admin-correto.pdf), banca Fundatec.

A PC-RS é usada nesta etapa somente para validar a arquitetura de sobreposição. Não existe trilha ativa nem promessa de conteúdo completo.

## Regras editoriais

- edital oficial define escopo, blocos e pontuação;
- lei oficial consolidada ancora itens jurídicos;
- questão autoral é sempre identificada como treino;
- frequência histórica só aparece após corpus representativo e rastreável;
- nenhum item extraído é publicado sem revisão humana;
- alteração legislativa exige revalidação dos itens ligados à norma.
